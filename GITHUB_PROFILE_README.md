### 🍕 Flagship Project: Online Food Delivery Web Application (`food_app_tap`)

> A complete full-stack web application designed and built with pure Java EE on Apache Tomcat 10.

```text
[ Browser (JSP Views) ] ──HTTP──> [ Controller (Servlets) ] ──> [ DAO & Models ] ──JDBC──> [ MySQL DB ]
```

* **Key Modules:**
  * 🔐 **Authentication & Session:** Secure register/login with `HttpSession` tracking via `UserDAOImpl` and `LoginServlet`.
  * 🍽️ **Restaurant & Menu Explorer:** Dynamic menu fetching with category filters via `MenuDAO`.
  * 🛒 **Smart Shopping Cart:** Real-time dish quantity modification, subtotal calculation, and session persistence (`CartServlet`).
  * 💳 **Checkout & Transactions:** Relational order records in `orders` and `order_items` tables with transaction safety.
  * 📦 **Order Tracking:** Detailed purchase history and delivery status management (`orderHistory.jsp`).
* **Tech Stack:** Java EE, Jakarta Servlets, JSP, JDBC, Apache Tomcat 10, MySQL, CSS3.
