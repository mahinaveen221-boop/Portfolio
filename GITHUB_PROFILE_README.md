### 🌟 Flagship Project: Online Food Delivery Web Application (`food_app_tap`)

> An end-to-end full-stack web application replicating an enterprise food ordering service.

- **Architecture:** 4-Tier MVC Architecture (`JSP Views` ➔ `Servlet Controllers` ➔ `DAO & Models` ➔ `MySQL DB`)
- **Key Features:**
  - 🔐 **User Authentication:** Registration, Login with hashed credentials, and secure session management.
  - 🍽️ **Restaurant & Menu Catalog:** Dynamic retrieval of restaurants and menu items via `MenuDAO`.
  - 🛒 **Smart Cart:** Dynamic quantity modification, real-time item subtotal calculations persisted in `HttpSession`.
  - 💳 **Checkout Pipeline:** Transaction-safe order creation with normalized relational schema across `orders` and `order_items`.
  - 📦 **Order Tracking & History:** Detailed order logs with item breakdown.
- **Tech Stack:** Java Servlets, JSP, JDBC, Apache Tomcat 10, MySQL, CSS3.
