## 🌍 2. How to Host Online for FREE (GitHub Pages - Live Website Link)

HR and Recruiters-ku anuppuradhuku ungaluku oru live link kedaikum (e.g. `https://yourusername.github.io`):

1. **GitHub-la New Repository create pannunga:**
   - [github.com/new](https://github.com/new) ponga.
   - Repository name: `portfolio` or `naveenraja-portfolio`.
   - Set as **Public** and click **Create repository**.

2. **Files upload pannunga:**
   - `C:\Users\acer\.gemini\antigravity\scratch\naveenraja_portfolio` folder-la iruka files (`index.html`, `style.css`, `script.js`, `resume.html`) upload pannunga.
   - Or terminal / git command moolama push pannalaam:
     ```bash
     cd C:\Users\acer\.gemini\antigravity\scratch\naveenraja_portfolio
     git init
     git add .
     git commit -m "Initial commit - Naveenraja K Portfolio"
     git branch -M main
     git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/portfolio.git
     git push -u origin main
     ```

3. **Enable GitHub Pages (1-Click):**
   - GitHub repo page-la **Settings** ➔ **Pages** (left sidebar) ponga.
   - **Branch:** `main` select panni **Save** click pannunga.
   - 1 minute-la ungalukku live link kedaichidum:  
     👉 `https://<YOUR_GITHUB_USERNAME>.github.io/portfolio`

## 🐙 3. GitHub Profile Portfolio Setup (`GITHUB_PROFILE_README.md`)

Recruiters ungaloda GitHub profile-ah paakumpodhu ultra-professional-ah iruka:

1. GitHub-la oru repo create pannunga with your exact GitHub Username (e.g. repo name: `naveenraja-k`).
2. Adha **Public** vechu, `Add a README file` tick pannunga.
3. Namma create panni iruka `GITHUB_PROFILE_README.md` content-ah copy panni anga paste pannidunga.
4. Ungaloda profile page-la dynamic stats, tech badges, and Food App showcase automatic-ah kaatum!
