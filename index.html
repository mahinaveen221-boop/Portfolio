End-to-End MVC Architecture Flow

Clean Layer Separation
1. View Layer (JSP)
`home.jsp`, `menu.jsp`, `cart.jsp`, `orderConfirmation.jsp` providing responsive, interactive user presentation.
2. Controller (Servlets)
`HomeServlet`, `MenuServlet`, `CartServlet`, `CheckoutServlet` handling HTTP requests & session state.
3. Model & DAO Layer
`UserDAOImpl`, `RestaurantDAOImpl`, `MenuDAOImpl`, `OrderDAOImpl` implementing business logic & queries.
4. MySQL Database
Normalized `food_app_db` containing relational tables for users, restaurants, menu items, orders & order items.

User Authentication & Sessions

Secure user signup and login handled via `LoginServlet` and `RegisterServlet` with session persistence, role validation, and logout security.

Restaurant & Menu Explorer

Dynamic catalog rendering of restaurant cards and dish menus with real-time availability checks and pricing retrieved through `MenuDAO`.

Dynamic Session Cart

Full cart capability supporting real-time add, quantity increment/decrement, item deletion, and subtotal calculation stored in `HttpSession`.

Checkout & Transactions

Checkout pipeline creating orders in the `orders` table and corresponding line items in `order_items` with transactional integrity.

Order History & Tracking

User-specific order history page (`orderHistory.jsp`) displaying previous purchases, order status (Pending/Confirmed), and item breakdown.

// CartServlet.java - Session-based Shopping Cart Management
package com.tap.servlet;

import java.io.IOException;
import java.util.HashMap;
import java.util.Map;
import jakarta.servlet.ServletException;
import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.*;
import com.tap.model.CartItem;

@WebServlet("/cart")
public class CartServlet extends HttpServlet {
    @Override
    protected void doPost(HttpServletRequest request, HttpServletResponse response) 
            throws ServletException, IOException {
        HttpSession session = request.getSession();
        Map cart = (Map) session.getAttribute("cart");
        if (cart == null) {
            cart = new HashMap<>();
            session.setAttribute("cart", cart);
        }

        String action = request.getParameter("action");
        int itemId = Integer.parseInt(request.getParameter("itemId"));

        if ("add".equals(action)) {
            String name = request.getParameter("name");
            double price = Double.parseDouble(request.getParameter("price"));
            cart.compute(itemId, (k, v) -> v == null ? 
                new CartItem(itemId, name, price, 1) : 
                new CartItem(itemId, name, price, v.getQuantity() + 1));
        } else if ("remove".equals(action)) {
            cart.remove(itemId);
        }

        response.sendRedirect("cart.jsp");
    }
}
